How Blair installs it (Gmail)

  1. Hit Copy signature (or click in the preview, Ctrl + A, Ctrl + C).
  2. Gmail → cog → See all settings → General → Signature.
  3. Create a new signature, click in the box, Ctrl + V.
  4. Set it as default for new emails and reply/forward. Save Changes.

Install via signature settings, not by pasting into the message body — that's what keeps phone/email clickable.
