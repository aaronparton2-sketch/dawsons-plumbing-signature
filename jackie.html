Outlook-ready. The logo and all icons are hosted online (not embedded), so they render in classic Outlook / Microsoft 365, which strips embedded images. Facebook and Instagram show a labelled white pill and click through correctly.

How to install it (Outlook / Microsoft 365)

  1. Hit Copy signature above (or click in the preview, Ctrl + A, Ctrl + C).
  2. Outlook → File → Options → Mail → Signatures (or in new Outlook: Settings → Mail → Compose and reply).
  3. Create a new signature, click in the box, Ctrl + V.
  4. Set it as default for new messages and replies/forwards. Save.

Best done on Outlook on your computer or Outlook on the web (outlook.office.com). The Outlook phone app can't hold a signature with images, so set it up on the desktop or web version and it'll come through on every send.

Install via signature settings, not by pasting into the message body, so the phone and email stay clickable.
